## 🔄 Automation Rules

### **Auto-Generated Message Sequences**

```
IF status = REPLIED AND time_since_reply < 2 hours:
  → Auto-generate Playbook 2 offer message
  → Log as DRAFT
  → WAIT for human review before sending

IF status = REPLIED AND time_since_reply > 2 days AND offer_sent = false:
  → Manual review needed
  → May have been distracted

IF offer_sent = true AND response = true AND time_since_offer < 3 days:
  → Send demo link
  → Mark DEMO_OFFERED

IF demo_completed = true AND time_since_demo < 1 day:
  → Send trial access email
  → Mark TRIAL_ACCESS_SENT
```
