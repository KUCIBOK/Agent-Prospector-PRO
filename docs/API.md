# Kucibok Prospector — API Documentation

> **Interactive docs available at**: `http://localhost:8000/docs` (Swagger UI)

---

## Base URL

```
http://localhost:8000/api
```

## Authentication

Currently, no authentication is required for local development. Production deployment should add:
- Bearer token authentication
- API key management
- Rate limiting

## Response Format

All responses are JSON:

```json
{
  "data": { ... },
  "status": "success",
  "timestamp": "2024-01-01T12:00:00Z"
}
```

Errors:
```json
{
  "detail": "Error message",
  "status": 400,
  "timestamp": "2024-01-01T12:00:00Z"
}
```

### Prospects

#### `GET /prospects`
List prospects with pagination and filtering.

**Query Parameters:**
- `page` (int, default=1) — Page number
- `page_size` (int, default=20, max=100) — Items per page
- `prospect_type` (string) — Filter by type: ARTIST, ART_ADVISOR, CURATOR, GALLERY, OTHER
- `status` (string) — Filter by status: IDENTIFIED, PREQUALIFIED, VERIFIED_KUCIBOK, etc.
- `priority` (string) — Filter by priority: P1, P2, P3, P4
- `country` (string) — Filter by country
- `search` (string) — Search by name or email

**Response:**
```json
{
  "total": 150,
  "page": 1,
  "page_size": 20,
  "items": [
    {
      "id": 1,
      "type": "ARTIST",
      "name": "Jean Dupont",
      "country": "SN",
      "city": "Dakar",
      "website": "https://...",
      "email": "...",
      "score": 82.5,
      "confidence": "HIGH",
      "priority": "P1",
      "status": "PREQUALIFIED",
      "created_at": "2024-01-01T12:00:00Z",
      "updated_at": "2024-01-02T12:00:00Z"
    }
  ]
}
```

#### `GET /prospects/{id}`
Get a specific prospect by ID.

**Response:** Single prospect object (same structure as above)

#### `POST /prospects`
Create a new prospect.

**Request Body:**
```json
{
  "type": "ARTIST",
  "name": "Jean Dupont",
  "country": "SN",
  "city": "Dakar",
  "website": "https://example.com",
  "email": "jean@example.com",
  "linkedin": "https://linkedin.com/in/...",
  "instagram": "@jean",
  "description": "Bio",
  "specialty": "Sculpture"
}
```

**Response:** Created prospect object (201 Created)

#### `PATCH /prospects/{id}`
Update a prospect.

**Request Body:** Any subset of prospect fields

**Response:** Updated prospect object

#### `DELETE /prospects/{id}`
Delete a prospect.

**Response:** 204 No Content

#### `GET /prospects/stats/by-type`
Get prospect counts by type.

**Response:**
```json
{
  "by_type": {
    "ARTIST": 45,
    "ART_ADVISOR": 23,
    "CURATOR": 18,
    "GALLERY": 12,
    "OTHER": 5
  }
}
```

#### `GET /prospects/stats/by-priority`
Get prospect counts by priority.

**Response:**
```json
{
  "by_priority": {
    "P1": 10,
    "P2": 25,
    "P3": 45,
    "P4": 23
  }
}
```

### Messages (Outreach)

#### `GET /messages`
List outreach messages (sorted by prospect priority).

**Query Parameters:**
- `page` (int, default=1)
- `page_size` (int, default=20)
- `status` (string) — DRAFT, SENT
- `outcome` (string) — REPLIED, MEETING, CUSTOMER, LOST, NOT_RELEVANT
- `persona` (string) — ART_ADVISOR, CURATOR

**Response:**
```json
{
  "total": 150,
  "pending": 45,
  "sent": 95,
  "replied": 10,
  "items": [
    {
      "id": 1,
      "prospect_id": 5,
      "persona": "CURATOR",
      "variant_label": "variant_1_short",
      "channel": "LINKEDIN",
      "content": "Hi Jean, ...",
      "status": "DRAFT",
      "outcome": "NONE",
      "generated_at": "2024-01-01T12:00:00Z",
      "sent_at": null,
      "model_version": "1.0"
    }
  ]
}
```

#### `GET /messages/{id}`
Get a specific message.

**Response:** Single message object

#### `POST /messages`
Create a new message (manual or generated by system).

**Request Body:**
```json
{
  "prospect_id": 5,
  "persona": "CURATOR",
  "variant_label": "variant_1_short",
  "content": "Hi Jean, ...",
  "channel": "LINKEDIN"
}
```

**Response:** Created message object (201 Created)

#### `PATCH /messages/{id}`
Update message status or outcome (manual tracking).

**Request Body:**
```json
{
  "status": "SENT",
  "outcome": "REPLIED"
}
```

**Response:** Updated message object

#### `DELETE /messages/{id}`
Delete a message (use sparingly — audit trail!).

**Response:** 204 No Content

#### `GET /messages/queue/draft`
Get all DRAFT messages ready to send (sorted by priority).

**Response:**
```json
{
  "total": 45,
  "messages": [...]
}
```

## Status Codes

| Code | Meaning |
|------|---------|
| 200 | OK |
| 201 | Created |
| 204 | No Content |
| 400 | Bad Request |
| 404 | Not Found |
| 409 | Conflict (e.g., duplicate) |
| 500 | Internal Server Error |

---

## Error Handling

All errors return a JSON object with details:

```json
{
  "detail": "Prospect not found",
  "status": 404
}
```

Common errors:
- `404 Not Found` — Resource doesn't exist
- `409 Conflict` — Duplicate (e.g., email already exists)
- `422 Unprocessable Entity` — Validation error (malformed request)
- `500 Internal Server Error` — Server error (check logs)

## Pagination

Use `page` and `page_size` query parameters:

```
GET /api/prospects?page=2&page_size=50
```

Default: page 1, 20 items per page. Maximum page size: 100.

## Filtering & Search

### By Type
```
GET /api/prospects?prospect_type=ARTIST
GET /api/prospects?prospect_type=ART_ADVISOR
```

### By Status
```
GET /api/prospects?status=IDENTIFIED
GET /api/prospects?status=PREQUALIFIED
```

### By Priority
```
GET /api/prospects?priority=P1
```

### By Country
```
GET /api/prospects?country=SN
```

### Search (Name, Email)
```
GET /api/prospects?search=Jean
GET /api/prospects?search=jean@example.com
```

### Combine Filters
```
GET /api/prospects?prospect_type=ARTIST&country=SN&priority=P1
```

## Examples

### List all P1 artists from Senegal
```bash
curl "http://localhost:8000/api/prospects?prospect_type=ARTIST&country=SN&priority=P1"
```

### Create a new prospect
```bash
curl -X POST "http://localhost:8000/api/prospects" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "ARTIST",
    "name": "Jean Dupont",
    "country": "SN"
  }'
```

### Get outreach queue (DRAFT messages)
```bash
curl "http://localhost:8000/api/messages/queue/draft"
```

### Mark a message as sent
```bash
curl -X PATCH "http://localhost:8000/api/messages/1" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "SENT"
  }'
```

### Get system summary
```bash
curl "http://localhost:8000/api/monitoring/summary"
```
