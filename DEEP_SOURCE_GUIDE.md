### **Data Extraction Process**

```python
for each_search_result in google_results:
    1. Extract curator name (ML-based)
    2. Extract gallery name (domain parsing)
    3. Visit website
    4. Extract email address (regex + parsing)
    5. Extract description (key sections)
    6. Check for duplicates
    7. Create Prospect object
    8. Add Source tracking
    9. Store in database
```
