🚨 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Build Failed?
  → Check Render Dashboard → Web Service → Logs
  → Look for error messages
  → Usually: missing package in requirements.txt

App Crashes?
  → Render Dashboard → Logs
  → Copy error message
  → Check it works locally first

Database Connection Error?
  → Verify DATABASE_URL variable
  → Verify PostgreSQL service is "Available"
  → Check URL format
  → Re-generate if needed

Can't see your app?
  → Check status is "Live"
  → Wait a few minutes
  → Refresh browser
  → Clear browser cache
